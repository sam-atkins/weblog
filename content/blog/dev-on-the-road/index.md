I’ve always decided against getting an iPad because I want a machine I can develop on. There are good options in this post to make an iPad enough of a dev machine to fix minor emergencies if you are on the road. One of the options is using [Gitpod.io](https://www.gitpod.io/). I've experimented with it before and was impressed.

Although if I had to choose between a MacBook or an iPad, I would still choose a MacBook.
